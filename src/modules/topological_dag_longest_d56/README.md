# DAG Longest Weighted Path & Critical Slack (`topological_dag_longest_d56`)

> Category: **Scheduling Graphs** | Language: **Python 3.11+**

## Overview

Computes earliest start, critical longest path distance, and zero-slack path counts across weighted directed acyclic dependency networks.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(V + E)` |
| **Space Complexity** | `O(V + E)` |

## Mathematical & Safety Invariants

- Longest path strictly satisfies dist[v] >= dist[u] + w along every directed edge.
