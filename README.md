# Computational Physics & Scientific Computing in Python

Research-grade computational implementations of Quantum Field Theory S-matrix scattering, 3D continuum elasticity, magnetohydrodynamics (MHD), symplectic Hamiltonian integrators, and Fourier optics.

## Classic Algorithms & Data Structures

In addition to the physics modules, this repository now includes canonical,
doctest-verified implementations of classic algorithms and data structures:

- `sorting/` - comparison and distribution sorts
- `dynamic_programming/` - optimal substructure and memoization problems
- `graphs/` - traversal, shortest paths, and flow algorithms
- `maths/` - number theory, primality, and elementary combinatorics
- `bit_manipulation/` - bitwise tricks and subsets
- `linear_algebra/`, `data_compression/`, `linear_programming/`
- `genetic_algorithm/`, `computer_vision/`

Each module is paired with a `test_*.py` doctest harness (run with `pytest`).
